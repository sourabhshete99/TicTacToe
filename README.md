# Tic-Tac-Toe Mobile Game (Jetpack Compose)

Built for **Android Studio Koala (2024.1+)** with Jetpack Compose & Kotlin 2.0.

### Features
1. Offline 2-Player Pass-and-Play mode
2. AI Bot Mode with realistic Coroutine delay and smart strategy
3. Reactive Status banner tracking turns, bot thinking state, win announcements, and draws
4. 3x3 Animated grid and reset controls

### Quick Run
- Open Android Studio Koala
- Open this root directory as an Android project
- Let Gradle sync and press Run!
